### 2. GitHub Issue Content Templates

#### Visual UI Debugging Issue
```markdown
# Visual UI Debugging for Flutter Apps - AI Should See What Developers See

## Problem
Cursor AI currently cannot "see" the visual output of Flutter applications, requiring developers to manually describe UI issues, take screenshots, and provide context that should be automatically available.

## Impact
- Reduced productivity (15-20 minutes per issue vs 2-3 minutes)
- Incomplete context for AI responses
- Frustrating workflow for obvious visual problems
- Missed opportunities for proactive problem detection

## Proposed Solution
- Real-time visual context integration
- Automatic issue detection and reporting
- Interactive UI testing capabilities
- Proactive problem prevention
```

#### Project Context Memory Issue
```markdown
# Project-Specific Context Memory - AI Should Remember Project History

## Problem
Cursor AI currently lacks the ability to maintain project-specific context, learnings, and domain knowledge across development sessions. This leads to repetitive mistakes, forgotten decisions, and the need to re-explain established patterns.

## Impact
- Repetitive mistakes and forgotten decisions
- Lost domain expertise and business logic
- Inefficient re-explanation of established patterns
- Development loops and inconsistent solutions

## Proposed Solution

- Learning from corrections and decisions

- Context-aware suggestions
```
